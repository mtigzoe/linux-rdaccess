Branch: `fix/nvda-orca-compat-live-edgecases`. Base: latest `origin/main`,

Eight pre-existing defects were established with failing behavioral paths:

| Defect | Root cause and correction | Regression evidence |
| --- | --- | --- |
| Ctrl did not stop native Orca 42 speech | The connector's `_get_speech_server()` queried `speech._state.server`; Orca 42 stores `_speechserver`. A strict updater repairs the known getter and retains the newer slot fallback. Local-only `old_stop` remains in use, avoiding an extra deferred NVDA cancel. | Native server was never stopped before repair; patched getter/controller tests cover repeats, coalescing, disconnect, and both slots. |
| Say All continued after cancellation/reconnect | Orca 42 posts END progress and the next iterator step as separate GLib callbacks. Native `stop()` only cancels synthesis. Guarded iterators/progress now carry run, stop, receive-time cancellation, and session ownership. | END-before-stop and same-transport reconnect previously forwarded `SECOND`; an END queued ahead of Ctrl's native stop produced `speak, cancel, speak`. All now reject the stale continuation. |
| F7 acted on a page from browser chrome | `documentFrame()` can return the active page while the address bar has focus. Initial invocation and chooser focus restoration now also check `inDocumentContent()`, with the snake_case fallback. | Three new chrome/context cases failed before the guards. |
| Deferred browser actions acted on stale context | Orca 42 delays keyboard consumers by one tick. The original event's script/action could outlive its browse mode, document, or remote session. Actions now retain the atomically claimed session epoch and recheck script/document/mode at consumption. | Browser/Elements baseline: 25 tests, 41 failing subcases; fixed: 25 passed. Includes forms, heading levels, find/layout, landmarks, table arrows/edges, release preservation, and reset during a mode query. |
| Remote braille width never sized Orca | The upstream display-info handler only notified a logging stub. Orca's viewport stayed at its default 32 cells. Valid 40/80-cell metadata now sizes the native viewport on GLib. | Both widths failed pan and last-cell routing before the fix. |
| Braille gestures survived display replacement | Pan/routing callbacks carried only session ownership, and routing was bounded by 1024 rather than the negotiated width. They now carry display ownership and expire when width changes or the display is unplugged. | Queued 80-cell gestures previously ran after replacement by a 40-cell display; obsolete routing indices are now rejected. |
| Restored focus could be silent | The prototype event announcer kept its duplicate cache after focus loss. Returning from a dialog inside 750 ms was discarded as a duplicate. Focus loss now expires only the departing object's entries without querying AT-SPI metadata. | Rapid dialog/field return and per-object expiration failed before repair; GTK focus/selection/descendant bursts still speak once. |
| Equal descriptions on different controls were suppressed | Description dedupe used text alone. It now includes accessible identity. | Two distinct fields with the same description and description repetition after focus return failed before repair. |

Review also caught and repaired adjacent failure paths introduced by these
changes: expired Say All END callbacks must clear the owned native script's
Say All flags without restoring its stale caret; braille cleanup must recognize
an independently replaced local BrlAPI size list even at the same width; a
failed braille refresh must roll back geometry/ownership and allow a same-width
retry. Each had a failing regression before the correction. Replacement Say
All runs and newer display owners retain their state.

Profiling preceded any optimization; no performance change was justified.
For 1,000 complete key pairs, final Python 3.10 receive/filter timing with a
recording backend was median **0.0348 ms**, p95 **0.0442 ms**; real isolated
XTest was median **0.0087 ms**, p95 **0.0090 ms**, mean **0.0123 ms**.
Python 3.12 results were receive/filter **0.0624/0.0744 ms** median/p95,
XTest **0.0078/0.0085 ms**, mean **0.0114 ms**. Synthetic marker pruning
dominates the receive profile when Orca does not drain markers. These figures
exclude network delivery, real AT-SPI queries, and audible synthesis; they do
not explain end-to-end "chunky" control. Existing <5 ms injection assertions
pass on both interpreters.
