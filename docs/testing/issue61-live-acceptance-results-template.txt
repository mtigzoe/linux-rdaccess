How to fill this in
-------------------
- Copy this file for each session. Fill in the SESSION RECORD first.
- Make one STEP BLOCK per step, using the step IDs from the procedure
  (for example H1.1, R1.3, M1a.5). Fill in the observed lines only after the
  step is done. Do not decide the result during the step.
- Record speech and braille separately. Never substitute local Orca speech,
  Linux-side checks or braille for Windows NVDA speech.
- Do not write relay addresses, channel keys, credentials, passwords or private
  text anywhere in this file.
- Result values: PASS, FAIL, INCONCLUSIVE, NOT RUN. For race attempts write
  "no failure observed in N attempts". INCONCLUSIVE if any unplanned input
  occurred.
- This record does not close #61, #57, #58, #59 or #72.
